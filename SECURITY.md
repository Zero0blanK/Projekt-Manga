# Security policy

## Supported versions

Security fixes go into the latest release. Please update before reporting a problem.

## Reporting a vulnerability

Please don't open a public issue for a security problem. Use
[private vulnerability reporting](https://github.com/Zero0blanK/Projekt-Manga/security/advisories/new)
instead, and include:

- The version you're using, and whether it's the desktop app or a self-hosted server
- What an attacker could do, and the steps to reproduce it

This is a project maintained in spare time, so replies may take a few days. Please keep the
details private until a fix is released.

## Scope

In scope: the app, the server, and the sandbox that runs sources. Problems in a source from a
third-party repository belong with that repository's maintainer, unless the source can escape
the sandbox.
